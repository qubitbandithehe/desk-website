# Desk — Tables for Modern Workspaces

A polished, minimal, and responsive website for **Desk**, a company designing and handcrafting tables for home offices, studios, and modern workspaces.

Built with **Next.js 16 (App Router)** and **TypeScript**, using pure CSS & CSS Modules for speed, zero external UI runtime bloat, and full responsiveness.

## ✨ Features

- **Header**: Responsive navigation with fixed header, blur on scroll, and working accessible mobile drawer.
- **Hero**: Minimalist typography, value proposition, quick actions, and product studio photography.
- **Featured Products**: 4 flagship tables (*Studio Oak*, *Loft Walnut*, *Arch Standing*, *Slim Ash*) with responsive card grid, pricing, and tag indicators.
- **Brand Story**: Design narrative focusing on durability, sustainable timber sourcing, and workshop craftsmanship.
- **Why Desk (Benefits)**: Four key highlights covering FSC-certified hardwoods, sturdy joinery, white-glove delivery, and 10-year warranty.
- **Customer Quote**: Testimonial section highlighting everyday usability and craftsmanship.
- **Call to Action**: High-contrast, focused exploration section.
- **Footer**: Multicolumn layout with navigation, brand information, and legal demo disclaimers.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Native CSS + CSS Modules (warm neutral palette, custom properties)
- **Icons & Assets**: Custom SVG favicon & responsive photographic assets

## 🚀 Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm or yarn or pnpm

### Run Locally

```bash
# Clone the repository
git clone https://github.com/qubitbandithehe/desk-website.git
cd desk-website

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build

```bash
npm run build
npm start
```
